## Requested change

> Add a get(doc, path, default=None) function to xmldictify for reading values out of a parsed document. The path is a string of keys separated by '/', for example get(doc, 'response/value/@a') returns the a attribute of value, and 'response/value/#text' its text. A path segment that is a whole number indexes into a list of repeated elements, so get(doc, 'root/item/1') is the second item. Because parse returns a single element as itself rather than a one-item list, index 0 on a single element returns that element and any other index on it is missing. If any step of the path is missing, return default. Keep parse and unparse working exactly as they do now.
